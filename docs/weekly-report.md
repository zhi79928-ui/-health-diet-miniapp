# 每周饮食与身体报告（1.17.0）

入口：打卡 → 查看每周报告。报告为独立页面，不继续拉长打卡页。

## 周期

- 默认报告期是昨天结束的最近 7 个完整自然日，不含尚未结束的今天。
- 对照期是报告期之前紧邻的 7 天。
- 页面标明两个周期的准确起止日期，并可按 7 天翻看更早周期；不能进入未来周期。

## 统计口径

- 饮食均值只使用至少确认过一餐的日期；未记录日期不补 0。
- “四餐均记录”只说明 4 个餐次都已确认，不表示营养一定完整。
- 热量、蛋白质、碳水、脂肪和膳食纤维比较两期的已记录日均值，不以百分比放大少量数据差异。
- 含未知膳食纤维食物时，明确显示部分数据提示。
- 体重和腰围分别显示本期最近一次、本期实际测量均值、测量次数及两期均值差。未测量日期不补值。
- 任一周期缺少对应数据时，不生成变化结论。

报告仅描述本机记录，不对饮食好坏、减脂效果、脂肪或肌肉变化作自动判断。

## 真机验收

1. 打卡页首屏点击“查看每周报告”，确认进入独立页面。
2. 核对默认周期不包含今天，且连续覆盖 7 天。
3. 创建有记录、无记录、四餐记录的不同日期，确认天数和餐数正确。
4. 核对某日未记录时不会降低日均营养；对照期无数据时显示“暂不比较”。
5. 保存不同日期的体重与腰围，确认次数、最新值、均值和差值。
6. 点击上一期、下一期，确认每次移动 7 天且不能越过最新一期。
