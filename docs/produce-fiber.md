# 蔬果、克数录入与膳食纤维

新增蔬菜、水果分类；搜索支持部分常用别名。新增食物只需选择食物与称重状态、输入克数，不再提供包装营养表录入。旧包装记录和自定义速查数据继续兼容，避免删除用户历史。

所有营养值按每 100 g 可食部分。生重指烹调前称重，干粮保留干重提示，水果去除不吃的果皮及果核。熟重条目注明做法和沥水要求；没有熟重数据时不做固定缩水换算。

## 数据来源（2026-09-22 核对）

- 香港食物安全中心《水果及蔬菜的营养素含量》，2007，附件 V，报告页 29–33：
  https://www.cfs.gov.hk/tc_chi/programme/programme_rafs/files/fruit%20and%20veg%20report_C%287.6.2007%29.pdf
  新增菜心、芥兰、小白菜、上海青、空心菜等蔬菜及香蕉、火龙果、香梨、猕猴桃等水果。采用完整数值条目，没有将“微量”或“没有资料”转成零。该报告部分数据源自 USDA SR19，和现有 SR Legacy 条目年代不同，因此不覆盖现有条目的热量及三大营养素。
- USDA FoodData Central 官方 API：/fdc/v1/foods。每项 sourceId 可在 https://fdc.nal.usda.gov/food-details/ID/nutrients 查询。
  水煮沥水西兰花 169967、水煮沥水胡萝卜 170394 采用独立熟重数据。
  现有主食、肉类、苹果、西兰花、杏仁等纤维依据原 sourceId 补齐；映射在 utils/foods.js。豆浆通用条目以及没有提供纤维的虾条目保留未知。

## 合计与兼容

纤维随克数缩放并保留一位小数。每餐及全天合计使用显示的分项数值；“已记录”只含已记录餐次。缺失纤维显示“暂无数据”，合计显示“已知合计，部分食物暂无数据”，不把缺失当作测定为零。

历史数据库食物可按相同 ID 和原克数补齐纤维，不改变原热量、蛋白质、碳水或脂肪。历史包装记录不推测纤维。纤维不重复加入热量计算，也不增加未请求的每日目标。

前端更新，无需重部署云函数。验证：npm test；新增 tests/produce-fiber.test.js 覆盖份量、嵌套合计、历史、保存重读、分类搜索及移除包装表单。

## 第二批扩充（2026-09-22）

新增 35 个条目；目前蔬菜 33 个条目（含独立熟重条目），水果 33 个条目。继续采用克数录入，没有增加包装录入。

新增番茄、去皮黄瓜、包菜、绿叶生菜、茄子、白萝卜、青甜椒、红甜椒、西芹、西葫芦、白蘑菇、鲜香菇、芦笋、鲜金针菇、秋葵，以及水煮包菜、菜花、菠菜。水果增加葡萄、蓝莓、甜樱桃、李子、杏子、油桃、网纹甜瓜、蜜瓜、石榴、柿子、龙眼、荔枝、榴莲、西柚、柠檬、黑莓、树莓。

前 12 个蔬菜条目通过 USDA FDC 官方 API 核对，其他新增条目来自 USDA SR28 官方报告（水果组 09、蔬菜组 11）。每条保存原始英文名称、FDC 或 NDB 编号和来源链接；每 100 g 可食部，纤维随克数缩放。网纹甜瓜仅为通用参考，不把它当成所有哈密瓜品种的精确数据；鲜龙眼不用于干桂圆，鲜香菇不用于干香菇。
