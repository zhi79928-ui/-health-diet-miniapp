# 1.23.0 今日页流程验收

本次只更新小程序前端，无需重新部署云函数。

1. 首次进入今日页显示三步指南；收起后重新进入不自动展开，点击“使用指南”仍可查看。
2. 添加食物后，已吃合计不增加；确认记录该餐后，合计与餐次状态更新。
3. 今日页只保留一份摄入总览，餐次默认折叠；点击餐次或顶部餐次快捷入口后展开食物、克数和记录操作。
4. 保存今日餐次后出现打卡引导，点击可回到打卡按钮。打卡仍需主动点击，无需记录满四餐。
5. 查看历史日期时，营养合计明确为所选日期；历史餐次提示不会计入今日打卡。
6. 点击餐次快捷按钮滚动至对应餐次；取消记录仍保留食物，重新记录后重新合计。
7. 备份入口跳转“我的”。指南收起偏好仅保存在本机，不进入健康记录备份。

自动测试覆盖存储失败时不显示保存成功、首次指南偏好、餐次记录与打卡分离，以及历史日期提示。
