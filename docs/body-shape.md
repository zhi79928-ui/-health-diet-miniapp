# 我的体型（1.17.1）

入口：我的 → 查看我的体型。独立页面，不改变底部导航。

使用本地生成的三维网格，以 WebGL 深度缓冲、平滑法线和多方向光照绘制；无外部模型、网络请求或照片上传。重做成人比例的头颈、面部、肩胸、腰腹、腿部和手足轮廓。支持水平旋转、有限俯仰、双指缩放和正侧背视角。仅交互时重绘，离开页面释放 GPU 资源。

模型默认以 20 秒一圈匀速自动旋转，并将持续绘制限制在约 30 帧/秒。触摸、拖动、缩放或修改输入时立即停止，结束操作 3 秒后恢复；用户可用页面按钮长期暂停或重新开启。切换到后台、离开页面及卸载页面时取消动画帧和恢复计时，避免后台继续占用 GPU。

输入有效数据后延迟 400 ms 更新预览。采用固定的每屏 250 cm 显示比例和共同脚底基线，避免自动适配抵消身高变化。默认正视投影的刻度与头顶辅助线对应实际模型高度；缩放或俯仰时隐藏刻度，点击正面、侧面、背面恢复。

腰部采用宽厚比固定的椭圆截面，半轴由输入围度及椭圆周长公式计算。修改腰围同时改变宽度和厚度，不使用上一版的截断上限。同身高、同体重下，较大的腰围会生成较粗的腰腹。这是几何参数映射，不代表真实脂肪分布。

模型是中性风格示意，不是人体扫描或经验证的人体预测。身高缩放整体，体重影响默认宽度，实测腰围调整腰部椭圆；肩宽、四肢及臀部等未测量部位仍是默认比例，不估计体脂或肌肉量。支持范围：身高 120–220 cm、体重 30–250 kg、选填腰围 40–200 cm。

预填健康设置身高、最近体重及腰围；没有数据时显示明确标注的示例，不自动保存示例。手动保存独立的 bodyShapeHistoryV1 本机快照（最多 30 次），不覆盖已有健康记录，也暂不纳入账号云备份。

真机验收：从“我的”进入，输入并更新；单指旋转、双指缩放；切换三个视角；保存、改变数据、点击历史快照；退出重新打开确认快照保留。检查空值、非法值提示和小屏滚动。模型渲染失败应显示提示。

重点比较：175 cm → 195 cm（脚底不变、头顶升高）；腰围 70 → 100 cm（正面变宽、侧面变厚）；保持同一视角及缩放进行比较。首次生成和手势流畅度仍需微信真机确认。
