# 我的体型（1.16.0）

入口：我的 → 查看我的体型。独立页面，不改变底部导航。

使用本地生成的三维网格，以 Canvas 2D 投影绘制；无外部模型、网络请求或照片上传。支持水平旋转、有限俯仰、双指缩放和正侧背视角。仅交互时重绘，离开页面取消绘制任务。

模型是中性风格示意，不是人体扫描或经验证的人体预测。身高缩放整体，体重影响默认宽度，实测腰围调整腰部椭圆；肩宽、四肢及臀部等未测量部位仍是默认比例，不估计体脂或肌肉量。支持范围：身高 120–220 cm、体重 30–250 kg、选填腰围 40–200 cm。

预填健康设置身高、最近体重及腰围；没有数据时显示明确标注的示例，不自动保存示例。手动保存独立的 bodyShapeHistoryV1 本机快照（最多 30 次），不覆盖已有健康记录，也暂不纳入账号云备份。

真机验收：从“我的”进入，输入并更新；单指旋转、双指缩放；切换三个视角；保存、改变数据、点击历史快照；退出重新打开确认快照保留。检查空值、非法值提示和小屏滚动。模型渲染失败应显示提示。
