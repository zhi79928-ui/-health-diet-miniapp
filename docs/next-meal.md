# 下一餐搭配 · 1.14.0

今日页新增“帮我搭配下一餐”。默认选首个尚未记录的餐次，可自行切换。每次三套，两组轮换。早餐、正餐、加餐各六套固定组合，营养值复用已有食物库，不调用 AI，也不上传记录。

有目标且已吃热量低于目标时，按未记录餐次的预设比例（早餐25%、午餐35%、加餐10%、晚餐30%归一化）分配参考余量。比较热量及三大营养相对差异，从模板80%～120%的离散份量中排序选取；不是精确营养优化或医疗处方。未记录的计划不计作已吃，也不能判断用户是否漏记。

没有目标或已达到热量目标时仅展示一般搭配。所有份量可调整，不要求补齐数字，不推荐跳餐。界面提醒核对过敏与忌口，目前不提供过敏自动过滤。

采用后只写入所选待记录餐次；已有食物须确认替换，已记录餐次不可选择。确认期间日期或记录变化时拒绝写入。存储失败保留选择界面与原数据。

## 真机验收

- 空白记录下打开，查看三套搭配；切换午餐/加餐检查内容不同。
- 换一组无重复，第三次回到第一组。
- 采用后可见待记录食物及克数，已吃合计不增加，确认记录后才增加。
- 目标餐已有食物：取消保留原餐，确认才替换。
- 历史日期不显示推荐入口；四餐都记录后提示已完成。
- 设置目标、记录一餐后查看说明和搭配；未设置目标时明确为一般示例。

仅前端更新，无需部署云函数或更改数据库权限。
