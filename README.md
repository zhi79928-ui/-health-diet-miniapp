# 轻体计划 · 微信小程序

一个无需后端即可运行的健康饮食计算小程序。用户填写身高、体重、年龄、性别和活动量后，可得到：

- BMI 与中国成人体重区间判断
- 基于成人公式的估算体脂率
- 减脂、维持塑形或健康增重建议
- 基础代谢、维持热量、目标热量
- 蛋白质、碳水化合物、脂肪目标
- 早午晚餐和加餐的具体食物克数，逐项标注生重、熟重、干重或可食部净重
- 鸡胸肉生重 / 烤熟熟重模式，100 g 对照和自定义克数蛋白质换算
- 各餐食物营养合计、全天合计与目标差额（差异较大时明确提示）
- 9 项食物每 100 g 营养参考和可复制的数据来源链接
- 本地保存最近一次输入，不收集或上传用户数据

## 运行

1. 下载并安装微信开发者工具。
2. 选择“导入项目”，目录选择本项目根目录。
3. 初次体验可继续使用 `touristappid`；准备发布时，把 `project.config.json` 里的 `appid` 换成你的小程序 AppID。
4. 点击“编译”即可预览。

## 计算说明

- BMI：体重（kg）÷ 身高²（m²）。
- 体脂率：使用 Deurenberg 成人估算公式，只适合趋势参考。
- 基础代谢：使用 Mifflin-St Jeor 公式。
- 目标热量：减脂为维持热量的 85%，增重为 110%，维持为 100%。
- 出于安全考虑，目标热量下限为男性 1500 kcal、女性 1200 kcal。

身高和体重本身无法准确测量体脂率。本项目要求年龄和性别来提高估算合理性，并在页面中清楚提示“公式估算”。如需更准确的数据，可在后续版本加入腰围、颈围和臀围，或接入体脂秤数据。

## v1.1 更新与本地使用

从 GitHub 重新下载 ZIP，解压到一个新文件夹后导入微信开发者工具；保留你原项目的 AppID 和本地配置，在新项目导入时填写自己的 AppID。使用 Git 管理本地项目的用户可先提交自己的修改，再拉取 main。

生成饮食方案后，在“一日参考食谱”切换鸡肉称重方式。页面底部的“鸡胸肉蛋白质速查”无需先生成方案即可使用，输入 150 g 应显示生重约 33.8 g 蛋白质、烤熟熟重约 46.5 g。

详细数据来源、称量口径与模板限制见 [营养数据说明](docs/nutrition-sources.md)。食谱数值为估算，请优先采用包装标签。生重 100 g 不是熟重 100 g，程序不使用固定缩水率。

## 发布前建议

- 在微信公众平台注册小程序并取得 AppID。
- 根据小程序服务类目与所在地要求，补齐隐私政策、用户协议与健康免责声明。
- 如需保存历史记录或账号同步，再接入微信云开发；当前版本不依赖服务器。

> 本项目结果仅用于一般健康管理参考，不用于诊断、治疗或替代医生/注册营养师的建议。
