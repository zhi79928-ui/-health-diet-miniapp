# 轻体计划 · 微信小程序

## v1.9：记录、趋势与可控云备份

五个底部入口：**今日、计划、食物、打卡、我的**。不登录也能记录；登录后可主动云备份，并可随时删除云端副本。

1. 在“计划”填写自己的信息，选择自动推荐、减脂、维持或增重目标。初次使用不再预填示例身体数据。
2. 生成后点击“保存为今日计划”。在“今日”点击每项食物的“换菜 / 改量”，选择另一种食物和生熟状态，可按蛋白质近似等量、热量近似等量或手动克数替换。
3. 每餐可增添或移除食物，克数按实际可食部填写。整餐、全天营养同步更新；不同食材不会自动保证所有营养都相等。
4. 吃完后点击“按以上食物记录这餐”，才计入已摄入和剩余目标。没全吃完请先修改实际克数。已记录餐需先取消记录才能修改，避免无意改变已吃历史。
5. 重新打开会恢复该日记录。可选历史日期、沿用前一天食谱；更新计划时保留已记录餐次，复制到新的一天不会复制“已吃”状态。
6. “打卡”支持 kg / 斤输入、历史日期、同日更新、修改和删除。展示最近 30 条体重曲线、近 7 天饮食营养均值和最近 14 个有计划日期的餐次记录；未记录日期不补值。
7. 添加食物支持主食、蔬菜、水果分类和名称搜索，直接点选条目并填写生重或熟重克数；可复制上一餐、昨日同餐，也可保存常吃搭配。

修复了原按体重分配宏量营养后，碳水下限可能导致宏量能量超过目标热量的问题。预算冲突会明确提示；采用软件预算约束缩放蛋白和脂肪，再计算碳水。按 4/4/9 换算与目标的偏差在 0.2 kcal 左右的取整误差内。此规则不是个体营养处方，目标冲突需要进一步评估。营养横条改为实际参考能量占比。

内置体脂率仍为公式估算。自主目标不等于医学适用性判断；体重偏轻时阻止生成减脂计划。当前仍是单日模板，未实现自动过敏筛选、预算规划、周食谱或基于体重自动调热量。

自定义食物速查保留；因可只填蛋白质、未必具备完整营养，自定义条目暂不用于完整食谱合计。完整食谱换菜采用有四项营养数据的内置食物。

记录默认存储于本机，不会自动同步。用户主动备份时，饮食、体重、打卡、常用餐及健康设置会上传到当前微信身份对应的云端副本；提醒只同步提醒时间和打卡状态。云端备份可单独删除，退出登录不会删除本机记录。

一个核心记录功能可离线使用、云备份与提醒按需启用的健康饮食计算小程序。用户填写身高、体重、年龄、性别和活动量后，可得到：

- BMI 与中国成人体重区间判断
- 基于成人公式的估算体脂率
- 减脂、维持塑形或健康增重建议
- 基础代谢、维持热量、目标热量
- 蛋白质、碳水化合物、脂肪目标
- 早午晚餐和加餐的具体食物克数，逐项标注生重、熟重、干重或可食部净重
- 食谱鸡胸肉生重 / 烤熟熟重模式；肉类速查支持 16 种常见肉类 / 部位、名称搜索、100 g 对照和自定义克数换算
- 自定义任意肉类名称，录入对应生重 / 熟重的每 100 g 蛋白质，可选填热量，支持 kcal / kJ；保存在本机供下次选择
- 各餐食物营养合计、全天合计与目标差额（差异较大时明确提示）
- 覆盖常见主食、肉类、33 个蔬菜条目与 33 个水果条目的生重 / 熟重克数记录和膳食纤维参考
- 本地保存记录；只有用户主动使用云备份或订阅提醒时才上传对应数据

## 运行

1. 下载并安装微信开发者工具。
2. 选择“导入项目”，目录选择本项目根目录。
3. 初次体验可继续使用 `touristappid`；准备发布时，把 `project.config.json` 里的 `appid` 换成你的小程序 AppID。
4. 点击“编译”即可预览。

## 计算说明

- BMI：体重（kg）÷ 身高²（m²）。
- 体脂率：使用 Deurenberg 成人估算公式，只适合趋势参考。
- 基础代谢：使用 Mifflin-St Jeor 公式。
- 目标热量：减脂为维持热量的 85%，增重为 110%，维持为 100%。
- 出于安全考虑，目标热量下限为男性 1500 kcal、女性 1200 kcal。

身高和体重本身无法准确测量体脂率。本项目要求年龄和性别来提高估算合理性，并在页面中清楚提示“公式估算”。如需更准确的数据，可在后续版本加入腰围、颈围和臀围，或接入体脂秤数据。

## v1.3 更新与本地使用

从 GitHub 重新下载 ZIP，解压到一个新文件夹后导入微信开发者工具；保留你原项目的 AppID 和本地配置，在新项目导入时填写自己的 AppID。使用 Git 管理本地项目的用户可先提交自己的修改，再拉取 main。

生成饮食方案后，在“一日参考食谱”切换模板鸡肉称重方式。底部“食物”页的“肉类蛋白质速查”无需先生成方案即可使用：先点下拉框选择肉类，再输入克数，自动显示生重和熟重各自的蛋白质、热量和数据来源。切换时保留输入重量；清空或输入无效克数时清除结果。例：选择牛肉（眼肉·去骨瘦肉），输入 200 g，生重约 45 g 蛋白质，烤熟熟重约 58.4 g。

每个选项限定部位、肥瘦或鱼种，并说明熟重做法。例如牛眼肉不能直接代表肥牛或牛腩，普通猪绞肉不能代表纯瘦猪肉，鳕鱼数据不代表所有鱼。“食物”页速查是独立计算器；要修改实际食谱，请到“今日”使用换菜功能，合计会随之更新。

内置选项：鸡胸、牛眼肉、猪绞肉、大西洋鳕鱼、去皮鸡大腿、带皮鸡大腿、带皮鸡琵琶腿、去皮鸡翅肉、火鸡胸、猪里脊、猪腰肋肉、羊肩臂瘦肉、养殖大西洋三文鱼、蓝鳍金枪鱼、罗非鱼和虾仁。可输入“鸡腿”“羊肉”“虾”等筛选下拉列表。带皮鸡大腿、鸡琵琶腿、去皮鸡翅、火鸡胸及猪里脊目前仅收录熟重；缺少的状态明确显示“暂无数据”，不套用另一状态。

列表里没有的肉类（例如某品牌鸭胸肉或牛肉卷）请选择“自定义肉类”：

1. 填写名称、部位或品牌。
2. 按包装标签或可靠食物成分表填写 **每 100 g 可食部蛋白质**，至少填一种状态。不要将每份含量直接填入每 100 g 栏位。
3. 热量选填，先确认标签单位是 kcal 还是 kJ。程序按 1 kcal = 4.184 kJ 转成 kcal 显示；切换单位是重新解释输入数字，不是自动转换输入框数字。
4. 填写熟重做法和数据来源后，输入实际吃的克数即可计算。“保存为常用肉类”会保存在当前微信环境本地，下次出现在下拉列表中。
5. 已保存条目可以修改或删除，最多保存 50 项。“重置”只重置计算输入，保留自定义肉类；清除小程序本地缓存或换设备不会自动同步。

自定义仅依据录入的数据计算，不会凭肉名自动猜测营养。仅填生重时不生成熟重结果，未填热量时显示“未提供热量”，不会当作 0 kcal。

详细数据来源、称量口径与模板限制见 [营养数据说明](docs/nutrition-sources.md)。食谱数值为估算，请优先采用包装标签。生重 100 g 不是熟重 100 g，程序不使用固定缩水率。

- 根据小程序服务类目与所在地要求，补齐隐私政策、用户协议与健康免责声明。
